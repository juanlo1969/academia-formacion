# academia-formacion
Desarrollo de una aplicación de gestión  de una BBDD de una academia de formacion # Academia de formación — Java + JDBC + H2   Modelo de tres tablas: PROFESORES (PK ID), ASIGNATURAS (PK ID, FK PROFESOR_ID) y ALUMNOS (PK ID, FK ASIGNATURA_ID). El ejemplo asume un profesor por asignatura y una asignatura por alumno.
